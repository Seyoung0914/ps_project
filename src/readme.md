학관 온라인 주문 프로그램

Data class

Menu - 음식 데이터 클래스: 음식의 이름, 음식의 타입(fry fry, 따스한동, H:plate, 든든한동, Asian Market)

Cook - 요리사 : 주문을 받고 요리를 하고 음식을 줌. 음식을 주문 받은 뒤에 1초마다 조리중 메시지 출력, 3초뒤에 조리 완료 출력

Customer - 손님: 주문을 하고 음식을 받음. 주문시에 잔액을 확인. 잔액이 부족하면 에러메시지.

Order: 주문 관리. 주문번호, 주문상태, 주문개수, 식당타입

Service: 각각의 과정들

Manager: 이어 주는 역할
